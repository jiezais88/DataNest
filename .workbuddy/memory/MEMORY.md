# DataNest 项目记忆

## 项目基本信息

- **项目名称**：DataNest
- **定位**：开源数据中台
- **核心差异化**：开发治理一体化
- **MVP 范围**：数据集成 + 数据开发调度 + 数据治理 + 数据资产目录 + 数据服务
- **非范围**：BI 可视化、技术选型（不在产品文档中定义）
- **开发模式**：Sprint 模式，先出总纲 PRD，后续细化模块 PRD

## 用户角色

- 数据工程师（P1）
- 数据分析师（P2）
- 治理管理员（P3）
