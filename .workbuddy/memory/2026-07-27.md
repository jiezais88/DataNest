# 2026-07-27 工作日志

## DataNest Sprint 2 产品 PRD

- **输出文件**：`docs/sprint2/DataNest-Sprint2-批量数据同步与数据标准-PRD.md`
- **交互式确认已锁定决策**：
    - 目标端仅支持 Doris（后续 Sprint 扩至其他数据源）
    - 保存数据源后自动采集：勾选复选框触发，非默认触发
    - 失败重试：任务级别可配置（0-3 次，间隔 1-30 分钟）
    - 告警通知：PRD 只写「支持告警通知」，不指定具体渠道
- **Sprint 2 范围（5 大模块）**：
    1. **批量数据同步**：创建/编辑/删除/执行/历史/日志；源端支持 MySQL/PostgreSQL/Doris，目标端固定 Doris；全量+增量模式；手动+Cron
       触发；同步后自动更新元数据
    2. **数据预览**：数据源列表 + 元数据管理页均支持预览前 100 行
    3. **保存后自动采集**：新增数据源时勾选复选框，自动创建一次采集任务
    4. **失败重试与告警**：可配重试次数和间隔；失败后自动告警
    5. **数据标准管理**：命名规范（表/字段、前缀/后缀/正则）+ 字段类型标准 + 合规检查
- **设计原则**：遵循 Sprint 1 PRD 的纯产品视角，无接口/表设计
- **版本**：v1.0
