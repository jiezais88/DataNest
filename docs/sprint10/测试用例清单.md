## 三、F3 API 网关 + 统计（5）

> 前提：2.1 创建的「验收_产品查询」处于**已发布**状态，Key 为 `YOUR_KEY`（QPS=5）

### 3.1 Key 认证（AC-6）

```bash

  "http://localhost:8080/api/data-service/open-api/v1/accept-products"
```

- [ ] 两次调用均返回 HTTP 401

### 3.2 限流 429（AC-7）

> Key QPS=5，连续调 6 次

```bash
for i in $(seq 1 6); do
  echo -n "第${i}次: "
  curl -s -o /dev/null -w "%{http_code}" \
    -H "X-API-Key: YOUR_KEY" \
    "http://localhost:8080/api/data-service/open-api/v1/accept-products"
  echo ""
done
```

- [ ] 前 5 次返回 200，第 6 次返回 429
- [ ] 429 响应头有 `Retry-After` 字段

- [ ] 保存成功，Key 详情显示已绑定该管道

### 4.3 端到端推送 < 10s（AC-10）

> 需要一个 WebSocket 客户端工具。推荐用浏览器控制台或 wscat。

**方式 A（浏览器控制台）**：

```javascript
// 打开 http://localhost:3000，F12 控制台粘贴执行
const ws = new WebSocket('ws://localhost:8080/api/data-service/ws/events', [], {
  headers: { 'X-API-Key': 'YOUR_KEY' }
});
ws.onopen = () => {
  console.log('[WS] 已连接');
  ws.send(JSON.stringify({ op: 'subscribe', pipelineId: 'PIPELINE_ID' }));
};
ws.onmessage = (e) => console.log('[WS] 收到事件:', e.data);
ws.onerror = (e) => console.error('[WS] 错误:', e);
```

**替换 `YOUR_KEY`（2.1 步的 Key）和 `PIPELINE_ID`（F4.0 步复制的管道 id）**

然后在新终端插入一行：

```bash
docker exec -i datanest-middleware-test-mysql mysql -u root -proot123 testdb \
  -e "INSERT INTO e2e_s10_accept_orders (order_no, region, amount) VALUES ('ORD-ACCEPT', '华中', 999.00)"
```

- [ ] WebSocket 控制台在 **10s 内**收到事件，格式含 `pipelineId` / `table` / `opType: INSERT` / `data`
- [ ] 事件中 `table` 为 `e2e_s10_accept_orders`，`data.order_no` 为 `ORD-ACCEPT`

### 4.4 无 Key / 未绑定管道拒连（AC-10）

```javascript
// 无 Key 连接
const ws2 = new WebSocket('ws://localhost:8080/api/data-service/ws/events');

```

- [ ] 连接被拒，`onclose` 触发，close code 为 `1002`（或直接被 403 拒绝）
