新增质量规则

质量规则类型新增「Python」——通过 Python 脚本对目标表数据做复杂校验，返回统计值并按阈值分级。
规则类型已从四类扩展为五类：完整性 / 唯一性 / 值域范围 / 自定义 SQL / Python。
规则名称 *
规则类型 *

先选数据源，再在下方选择该数据源下的表。
目标表 *
检查字段 （可选，Python 脚本内通过 read_table 拉取该表数据）
Python 脚本 *
def check(df) python · 沙箱执行
def check(df): """接收目标表 DataFrame，返回 {'指标名': 数值}""" import pandas as pd if df.empty: return {'null_rate': 0.0} # 计算金额字段空值率 null_rate = df['amount'].isnull().mean() return {'null_rate': null_rate}
约定：`def check(df)` 接收目标表 DataFrame；内部可调用 `read_table(table, where=None, limit=None)` 按需采样；返回 dict 统计值。
返回指标（结果指标）*
从脚本返回 dict 中选择一个键作为结果指标，用于后续阈值分级判定。
阈值判定
警告阈值
严重阈值
权重
判定：value < 警告 → 通过；警告 ≤ value < 严重 → 警告；value ≥ 严重 → 严重；脚本失败 → 不可用（不告警）。
