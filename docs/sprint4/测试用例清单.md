## 一、登录与基础流程

### E2E-01 用户登录进入首页

- **优先级**：P0
- **步骤**：
    1. 访问 `/login`
    2. 输入用户名 `admin`、密码 `admin123`
    3. 点击「登 录」
- **预期结果**：
    - 跳转至首页 `/`
    - 页面显示「欢迎回来」及用户名

### E2E-02 创建 DAG 项目

- **优先级**：P0
- **步骤**：
    1. 进入 `/engineering/dags`
    2. 点击「新建项目」
    3. 填写项目名称和描述
    4. 点击保存
- **预期结果**：
    - 项目出现在列表中
    - 刷新后项目仍存在

- **优先级**：P0
- **前置条件**：已存在项目
- **步骤**：

    4. 连接节点边
    5. 保存 DAG
- **预期结果**：

    - 刷新后画布节点和边正确展示

## 二、Python 任务节点

### E2E-04 拖拽 Python 节点到画布并保存

- **步骤**：
    1. 打开 DAG 编辑页
    2. 从左侧节点面板拖入「Python 节点」
    3. 双击节点打开编辑器

    3. 等待执行完成
- **预期结果**：

## 六、SQL 血缘自动上报

> 本模块以 API 断言为主，E2E 中在综合流程里间接验证。

### API-19 CTAS SQL 血缘上报

- **优先级**：P0
- **对应验收**：AC-11 / G8
- **步骤**：
    1. 执行 `CREATE TABLE target AS SELECT * FROM source`
    2. 查询 `lineage_record` 表或 governance 接口
- **预期结果**：存在 source → target 血缘记录，含 dagId、nodeId、executionId

### API-20 INSERT INTO SQL 血缘上报

- **优先级**：P0
- **步骤**：执行 `INSERT INTO target SELECT * FROM source`，查询血缘记录
- **预期结果**：存在 source → target 血缘记录

### API-21 CREATE VIEW SQL 血缘上报

- **优先级**：P0
- **步骤**：执行 `CREATE VIEW v AS SELECT * FROM source`，查询血缘记录
- **预期结果**：存在 source → view 血缘记录

### API-22 纯 SELECT 不上报血缘

- **优先级**：P1
- **步骤**：执行 `SELECT * FROM source`，查询血缘记录
- **预期结果**：无该执行相关的血缘记录

### API-23 血缘解析准确率抽样

- **优先级**：P1
- **对应验收**：NAC-5
- **步骤**：准备 20+ 条常用 CTAS/INSERT/CREATE VIEW SQL，逐条解析或执行后查库
- **预期结果**：解析准确率 > 95%
