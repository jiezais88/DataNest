选择查询定义方式

决定 API 的查询逻辑来源。选表适合简单查询；自定义 SQL 支持多表 JOIN / 聚合 / 子查询等复杂口径。

选表 简单查询

从一张表生成接口，支持字段筛选 / 排序 / 分页。适合单表维度查询，配置简单。

自定义 SQL 灵活 · 复杂口径

编写只读 SQL（支持多表 JOIN / 聚合 / 子查询 / CTE），将加工后的结果封装为接口。限定单一数据源内查询。

自定义 SQL 为只读查询，保存时将校验涉及的每一张表：机密表不可生成对外 API，超出你的数据权限的表将导致整体拒绝。

定义 SQL

编写只读 SELECT。SQL 中的 :参数名 会自动识别为 API 参数（如 :startDate）。
仅展示当前用户可访问且已采集元数据的数据源
orders_region_sum.sql 格式化校验 SQL ✓ 
SELECT r.region_name,
       SUM(o.amount) AS total_amount,
       COUNT(*) AS order_cnt
FROM ods.orders o
JOIN dim.region r ON o.region_id = r.id
WHERE o.order_date >= :startDate
  AND o.status IN ('PAID', 'SHIPPED')
GROUP BY r.region_name
ORDER BY total_amount DESC

GET · 只读 自定义 SQL API 固定为 GET（只读定位）
