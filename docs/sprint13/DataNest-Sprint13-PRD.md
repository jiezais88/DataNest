# Sprint 13：数据服务自定义查询 SQL PRD

> **文档状态**：v1.0（细化版，承接二期总 PRD §7.0） | **作者**：产品通 | **关联文档**：`../DataNest-二期总PRD.md`（v1.5）、`../DataNest-二期总技术文档.md`（v1.4）、`../sprint10/DataNest-Sprint10-PRD.md`（一期数据 API 基准）
>
> **Sprint 目标**：让数据 API 从「选表参数化查询」升级为「选表 + 自定义 SQL」双形态——工程师可直接编写一段**只读 SQL**（JOIN/聚合/子查询）封装成对外 RESTful API，业务系统消费加工后的数据口径，无需先建中间表、无需暴露原始表。

---

## 1. 问题陈述

### 1.1 为什么 Sprint 13 做这件事

一期 Sprint 10 交付了数据 API（DS-02）：**选表 → 字段筛选/排序 → 对外 GET 接口**。它解决了"把一张表开放给业务方"的需求，但只能表达**单表简单查询**。业务系统真正高频要消费的是**加工后的口径**——例如：

- 「近 7 天各区域订单金额汇总」（`orders` JOIN `region` 后 GROUP BY）
- 「本月续费率 TOP 客户列表」（多表 JOIN + 复杂过滤）
- 「按条件查订单明细并带上用户维度」（JOIN + 参数化过滤）

一期面对这类需求只有三条路，全都不理想：

| 方案 | 代价 |
|------|------|
| 在数仓建一张中间表，再选表生成 API | 污染数仓、多一次加工与维护、口径散落 |
| 把原始表开放，让业务方自己拼 SQL | 数据口径失控、业务方门槛高 |
| SQL 终端查出结果人工导出 | 无法对外、无法实时 |

一期 Sprint 10 PRD 的 **NG8** 已明确把「复杂 JOIN / 自定义 SQL 接口」列为未来项。二期 Sprint 13（规划到最前，P2-D14）正是补上这个缺口。

### 1.2 Sprint 13 要达到的状态

> 工程师在数据 API 创建向导里**直接写一段只读 SQL**，配好参数与安全校验，一键生成对外 API——业务系统像调用普通数据 API 一样调用它，得到的是**加工后的结果**，而不是原始表。

## 6. 功能详细交互

### 6.1 入口与查询定义形态（新建向导·第 1 步）

```
┌─ 新建 API ─────────────────────────────────────────────────────┐
│  第 1 步 · 选择查询定义方式                                      │
│                                                                │
│  ○ 选表（推荐）                                                 │
│    从一张表生成接口，支持字段筛选/排序/分页，适合简单查询       │
│                                                                │
│  ● 自定义 SQL（灵活）                                           │
│    编写只读 SQL（支持多表 JOIN / 聚合 / 子查询），适合复杂口径   │
│    注：限定单一数据源内查询                                      │
│                                                                │
│                                        [下一步]                │
└────────────────────────────────────────────────────────────────┘
```

**交互说明**：
- 新建 API 向导第一步新增「查询定义方式」单选；**选表形态 = 一期现有流程完全不变**。
- 从资产详情/元数据「生成 API」带入时，仍走选表形态（保持现状）；自定义 SQL 从 API 管理页进入。

### 6.2 自定义 SQL 定义（第 2 步）

```
┌─ 新建 API · 自定义 SQL ─────────────────────────────────────────┐
│  数据源 *  [Doris 数仓 ▼]   （限定单数据源，展示当前用户可访问） │
│                                                                │
│  SQL（只读）*                                                   │
│  ┌────────────────────────────────────────────────────────┐   │
│  │ SELECT r.region_name, SUM(o.amount) AS total            │   │
│  │ FROM ods.orders o                                       │   │
│  │ JOIN dim.region r ON o.region_id = r.id                 │   │
│  │ WHERE o.order_date >= :startDate                        │   │
│  │ GROUP BY r.region_name                                  │   │
│  │ ORDER BY total DESC                                     │   │
│  └────────────────────────────────────────────────────────┘   │
│  [校验 SQL] [试跑预览]                                          │
│                                                                │
│  参数（由 SQL 中的 :参数名 自动识别）                            │
│  │ 参数名      类型       必填   默认值                        │
│  │ startDate   日期       ☑     ──                            │
│  │ （可手动补充类型/必填/默认值，删除自动识别出的参数）         │
│                                                                │
│  涉及表：ods.orders · dim.region（共 2 张，将用于权限校验）     │
│                                                                │
│  预览结果（前 100 条）                                          │
│  │ region_name │ total       │                                │
│  │ 华东        │ 12,345,678  │                                │
│  │ 华南        │ 9,876,543   │                                │
│  └───────────────────────────┘                                │
│                                          [下一步：配置接口]     │
└────────────────────────────────────────────────────────────────┘
```

**交互说明**：

- **数据源单选**：限定单一数据源（P2-D15），仅列出当前用户可访问、且已采集元数据的数据源（含内置 Doris）。
- **SQL 编辑器**：复用 SQL 终端的 Monaco 编辑器（语法高亮、格式化、Ctrl+Enter 校验）；**只读 SQL**，支持 SELECT/JOIN/聚合/子查询/CTE。
- **只读校验（CS-02）**：点击「校验 SQL」或保存时执行——复用 SQL 终端只读校验（JSqlParser 分类），拦截 INSERT/UPDATE/DELETE/DDL/多语句（分号检测，`;` 后非空即拒）。
- **参数识别（CS-03）**：SQL 中 `:参数名` 占位符自动识别为 API 参数（命名参数风格，防注入——参数一律 PreparedStatement 绑定，绝不拼接）。
  - 参数类型：默认自动推断（整数/小数/日期/字符串），工程师可手动修正；
  - 必填：默认必填，可改为选填（选填参数缺省时不带该条件）；
  - 默认值：可填（选填参数的默认值）。
- **涉及表（CS-05 前置）**：SQL 校验通过后解析涉及的表清单（含 JOIN/子查询），实时展示，用于下一步权限校验与血缘。
- **试跑预览（CS-04）**：点击「试跑预览」在**当前数据源**执行 SQL（参数填默认值/示例值），返回前 100 条；预览只读、带超时。
- **校验失败**：错误信息行内展示（非只读/语法错误/参数缺失等），不阻断但禁止进入下一步。

### 6.3 配置接口（第 3 步，复用一期）

```
┌─ 新建 API · 配置接口 ───────────────────────────────────────────┐
│  API 名称 *  [订单区域汇总]      API 路径 * /open-api/v1/region-sum │
│  请求方法    GET（只读，固定）                                   │
│  分页        ☑ 启用（page/pageSize 默认 1/20，上限 100）          │
│  自动文档    ☑（参数表自动生成 OpenAPI 描述 + curl 示例）         │
│                                                                │
│  API 预览                                                        │
│  GET /open-api/v1/region-sum?startDate=2026-08-01&page=1&size=20│
│                                          [下一步：绑定 Key]      │
└────────────────────────────────────────────────────────────────┘
```

**交互说明**：
- 名称/路径/分页/文档全部复用一期规则（路径归一、查重、段规则 `^[a-z0-9][a-z0-9-_]{0,99}$`）。
- 请求方法固定 GET（只读定位）；SQL 内联参数与分页参数合并进 API 文档参数表。
- **字段裁剪差异**：自定义 SQL 的返回列由 SQL 决定（工程师已在 SQL 里选好），**不再提供字段白名单勾选**（与选表形态不同，选表仍需字段裁剪）。

### 6.4 绑定 API Key（第 4 步，复用一期）

- 复用一期「绑定已有 Key / 新建 Key」交互，无差异。

### 6.5 安全闸门（CS-05，fail-closed）

| 校验 | 规则 | 不通过时 |
|------|------|----------|
| 只读校验 | SQL 必须为单条只读 SELECT | 拒绝保存，行内提示 |
| 敏感度闸门 | 涉及表**任一**为机密 → 拒绝；内部表未超管特批 → 拒绝（复用一期 governance-api 校验） | 拒绝创建，提示具体表名 |
| 数据权限闸门 | 涉及表**任一**超出当前用户/角色数据权限（数据源/库/表三级）→ **整体拒绝**（P2-D15） | 拒绝创建，提示无权限表 |
| 注入防护 | 参数一律 PreparedStatement 绑定；SQL 文本本身不拼接用户输入 | — |

> **关键语义（P2-D15）**：自定义 SQL 涉及多张表时，**只要有一张表用户无权限或为机密/未特批内部，整个 API 创建/调用即被拒绝**（fail-closed），不做部分放行——宁可误拒，不可漏放。

### 6.6 发布与调用（CS-06，复用一期）

- 状态机 `CREATED → PUBLISHED → DISABLED → 删除`、Key 认证、限流、熔断、调用统计、软删全部复用一期，**对外调用路径与选表 API 完全一致**（`/api/data-service/open-api/v1/{path}?参数=值`）。
- 调用时：参数绑定 → 执行 SQL（带超时）→ 分页 → 返回结果集；`api_call_log` 正常统计。

### 6.7 血缘解析（CS-07）

- **创建/编辑保存时**解析自定义 SQL 的表级血缘（涉及表清单 → 写入血缘图谱，作为「查询来源」节点），与任务血缘同一图谱；表详情页可看到"被哪些自定义 SQL API 引用"。
- 字段级血缘本期不做（NG：字段级解析收益有限，留未来）。

### 6.8 编辑与详情

- 编辑页：SQL 只读展示/可改（改后重新校验 + 重新过闸门）；参数表可改。
- 详情页：新增「SQL 定义」区块（SQL 文本 + 涉及表 + 参数表），其余复用一期（文档/Key/统计）。

## 10. 风险与对策

| # | 风险 | 影响 | 对策 |
|---|------|------|------|
| R1 | **SQL 注入**：自定义 SQL 文本 + 参数拼接 | 数据泄露 | 参数一律 PreparedStatement 绑定；只读校验拦截写语句；涉及表权限 fail-closed（二期总技术文档 R6） |
| R2 | **复杂 SQL 血缘解析覆盖度**：CTE/窗口函数等语法 | 血缘缺失 | 解析器覆盖度预验证，缺失语法降级为表级解析 + 记录，不阻断 |
| R3 | **参数类型推断错误**（如日期被当字符串） | 查询报错/结果错 | 类型可手动修正；预览可提前暴露；类型推断规则固化进技术文档 |
| R4 | **复杂 SQL 性能**：JOIN 大表慢查询拖垮网关 | 服务影响 | 执行超时 + 结果截断 + 建议在 Doris 建预聚合表（物化视图 Sprint 20） |
| R5 | **与多租户改造的衔接**（Sprint 14） | 返工 | 自定义 SQL 保存 `datasource_id`，Sprint 14 多租户时随数据 API 统一补租户维度 |
| R6 | **敏感列暴露（已知边界，用户确认）**：自定义 SQL 返回列由 SQL 决定，非机密表的敏感列可能被 API 暴露 | 数据泄露风险 | 靠表级敏感度闸门 + 数据权限 + 审计兜底；标注为已知边界（字段级敏感度留未来，NG5） |
