## 一、双形态向导与 SQL 定义（7）

> 本节会反复用到两段 SQL，先复制好：
>
> **【SQL-1 主链路 SQL】**
> ```sql
> SELECT r.region_name AS region_name, SUM(o.amount) AS total
> FROM datanest.e2e_s13_orders o
> JOIN datanest.e2e_s13_region r ON o.region_id = r.region_id
> WHERE o.order_date >= :startDate
> GROUP BY r.region_name
> ORDER BY total DESC
> ```
>
> ⚠️ **注意**：`:startDate` 是平台参数占位符，**不能直接执行**（直接跑会查不到数据）。
> 在向导里粘贴后点「校验 SQL」识别参数 → 参数类型选 DATE → 「试跑预览」自动用示例值 `2026-01-01` 替换 → 返回 3 行（SOUTH 400 / NORTH 350 / EAST 300）。
> 若在 SQL 终端单独验证，请把 `:startDate` 手动替换为 `'2026-01-01'`。
>
> **【SQL-2 非法 SQL】**
> ```sql
> DELETE FROM datanest.e2e_s13_orders
> ```

## 五、发布 + 对外调用（6）

> **Postman 用法（通用）**：新建请求 → 方法选 GET → 地址栏粘贴给出的 URL → 「Headers」页签添加一行：Key=`X-API-Key`，Value=你保存的 Key → 「Params」页签按用例添加参数 → 点 Send → 看响应体（JSON）。

### 5.1 发布 + 正常调用

1. 「API 管理」→ 打开「e2e_s13_验收区域汇总」详情 → 点「发布」

- [ ] 状态变「已发布」
2. Postman 请求：
   ```
   GET http://localhost:8080/api/data-service/open-api/v1/e2e-s13-accept-region-sum?startDate=2026-01-01
   ```
   Header：`X-API-Key: <你的Key>`

- [ ] 响应 code=200，data.records 3 行，data.total=3
- [ ] 第一行 region_name=`SOUTH`、total=`400`；其余 `NORTH 350 / EAST 300`

### 5.2 ⭐ 分页保持 SQL 内排序

1. Postman（同一 URL 与 Key），Params 添加 `page=1`、`pageSize=10`：
   ```
   GET .../e2e-s13-accept-region-sum?startDate=2026-01-01&page=1&pageSize=10
   ```
- [ ] records 顺序为 `SOUTH → NORTH → EAST`（**不是** EAST 开头）

2. Params 改为 `page=2`、`pageSize=1`
- [ ] 只返回 1 行，region_name=`NORTH`（分页偏移按 SQL 排序正确）

### 5.3 外部排序参数被忽略

1. Postman 加参数 `orderBy=total ASC`（其余同 5.1）
- [ ] 结果仍按 SQL 内排序（首行 SOUTH），外部 orderBy 不生效

### 5.4 缺少必填参数

1. Postman **不带** startDate，只带 Key：
   ```
   GET .../e2e-s13-accept-region-sum
   ```
- [ ] 返回 HTTP 400，body code=9018（缺少必填参数 startDate）

### 5.5 注入防护

1. Postman 传带注入片段的参数：
   ```
   GET .../e2e-s13-accept-region-sum?startDate=2026-01-01%3B%20DROP%20TABLE%20datanest.e2e_s13_orders
   ```

- [ ] 返回 200 或参数错误 400，**不会**执行删除
2. 「SQL 查询终端」执行 `SELECT COUNT(*) FROM datanest.e2e_s13_orders`

- [ ] 结果仍为 6（表未被删除）

### 5.6 结果截断 1000 行

2. 名称 `e2e_s13_验收截断`、路径 `e2e-s13-accept-big` → 完成创建 → 详情页点「发布」

3. Postman 调用：
