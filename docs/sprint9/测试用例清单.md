## 一、F1 运行监控（7）

> 入口：`数据工程 → CDC 管道`。以下在表 `e2e_s9_cdc_users` 上操作（已播种 3 行 seed_a/b/c）。

3. ③ 确认启动：预检自动执行 → 点「仅保存」

- [ ] 预检全绿（连通/binlog/ROW/库存在）；Checkpoint 摘要显示「实时（10 秒）」
- [ ] 保存后列表出现：状态「已停止」、创建人有值

## 附录 B：临时调低延迟阈值（3.3 用，验完还原）

> `lag.warn-threshold` 是 `@Value` 注入，**改 Nacos 后必须重启 realtime 才生效**（非热刷新，类无 `@RefreshScope`）。

```bash
# 1. 读当前配置 → 把 warn-threshold: 30 改为 1 → 发布
# 2. 重启 realtime 使新阈值生效
docker restart datanest-app-realtime
# 3. 等 realtime healthy（~40s）
# 验收完把阈值还原为 30 再重启一次
```

发布 Nacos 用带 token 的方式（Nacos 已开启鉴权，匿名读返回 403 JSON，会破坏配置）。

## 附录 C：Flink 重启策略（3.5 FAILURE 前置）

> 已验证：DROP 源表 → 作业优雅结束（FINISHED，不触发 FAILURE）；DROP Doris 目标表 → sink 写失败 → RESTARTING 无限重启到不了 FAILED。需 Flink 集群限制重启次数：

- `docker-compose.yml` / `shared-configs/shared-realtime.yaml` 已加 `restart-strategy.fixed-delay.attempts=3`，重启 Flink 集群生效。
- 未配时 FAILURE 告警无法通过作业失败真实触发（会 RESTARTING 循环），只能跳过或仅看链路。
