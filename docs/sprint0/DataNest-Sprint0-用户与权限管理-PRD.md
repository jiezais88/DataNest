# Sprint 0：用户与权限管理 PRD

> **版本**：v1.0 | **日期**：2026-07-23 | **作者**：产品通
>
> **Sprint 目标**：搭建用户体系——让平台有"谁在操作"的概念，为后续所有模块的权限控制打下基础。

---

## 1. 问题陈述

### 1.1 Sprint 0 为什么需要用户体系

没有用户体系的数据平台就像一个没有门的房子——谁都能进，谁都能看到一切，谁都能改任何配置。Sprint 1 的数据源连接、后续的同步任务、DAG
开发、数据查询，每一步都需要回答"谁在操作？他有没有权限？"

**在 Sprint 0 就把用户体系建好，而不是等到 Sprint 10 再补**，能避免：

- 前期开发时所有接口裸奔，上线后紧急加固
- 权限模型和业务逻辑耦合过深，后期重构成本极高
- 测试和演示时无法区分不同角色的体验

### 1.2 Sprint 0 要达到的状态

> **用户能注册和登录，管理员能创建用户并分配角色，每个 API 调用都带着"谁在操作"的上下文。**

## 5. 功能详细交互

### 5.1 登录

#### 5.1.1 登录页面

未登录用户访问任何 DataNest 页面，统一跳转到登录页。

登录页布局为居中卡片式，品牌 Logo 在上方，表单在中间：

```
┌──────────────────────────────────┐
│          DataNest                │
│       开源数据中台                 │
│                                  │
│  ┌────────────────────────────┐  │
│  │  用户名                    │  │
│  │  [___________________]    │  │
│  │                            │  │
│  │  密码                      │  │
│  │  [___________________] 👁  │  │
│  │                            │  │
│  │  ☐ 记住登录状态（7天）     │  │
│  │                            │  │
│  │  [      登 录      ]      │  │
│  └────────────────────────────┘  │
│                                  │
│  没有账号？联系管理员创建          │
└──────────────────────────────────┘
```

**交互说明**：

- 用户名和密码都为空时，「登录」按钮为灰色不可点击
- 填写用户名和密码后，按钮变蓝可点击，也支持回车键提交
- 登录过程中按钮显示 loading 动画 + "正在登录..."
- 密码输入框右侧 👁 图标可切换明文/密文

#### 5.1.2 登录成功

登录成功后：

- 跳转到首页（暂定数据集成页面，因为 Sprint 1 最先完工的是数据源管理）
- 右上角显示当前用户的头像（首字母）+ 用户名
- 左侧导航菜单根据用户角色动态显示（见 5.4）

#### 5.1.3 登录失败

三种失败场景，每种给出明确提示：

| 场景         | 提示文案                                            |
|--------------|-----------------------------------------------------|
| 用户名不存在 | "该用户不存在，请检查用户名或联系管理员创建账号"    |
| 密码错误     | "密码错误，你还可以尝试 N 次"（不做锁定时这句没有） |
| 账号已被禁用 | "该账号已被禁用，请联系管理员"                      |

所有错误提示在表单上方以红色卡片形式展示，带 ❌ 图标。点击关闭或 5 秒后自动消失。

#### 5.1.4 登录状态保持

勾选"记住登录状态"后，Token 有效期 7 天；不勾选则 2 小时无操作后自动退出。退出后再次访问任何页面跳回登录页。

### 5.2 用户管理（管理员视角）

#### 5.2.1 进入页面

管理员登录后，左侧导航比普通用户多一个「系统管理」分组，包含：

- 用户管理

> **Sprint 0 不做角色管理 UI**：角色（4 个预置角色）和权限矩阵在数据库初始化阶段通过 Flyway 脚本直接写入，不提供界面操作。后续
> Sprint 12 再补可视化角色管理和自定义角色。

点击「用户管理」，进入用户列表页。

**空状态**：初始部署只有一个默认管理员账号（`admin`），列表中仅此一个用户。

**列表状态**：

```
┌──────────────────────────────────────────────────────────┐
│ 用户管理                                    [+ 创建用户]  │
│                                                          │
│ 🔍 [搜索用户名...]    [全部角色 ▼]    [全部状态 ▼]   [查询] [重置] │
├────────┬──────────┬──────────┬────────┬────────┬───────┤
│ 用户名  │ 角色      │ 邮箱      │ 状态    │ 创建时间 │ 操作  │
├────────┼──────────┼──────────┼────────┼────────┼───────┤
│ admin  │ 超级管理员 │ admin@xx │ ✅ 正常 │ 2026-.. │ 详情  │
│        │          │          │        │        │ 编辑  │
│        │          │          │        │        │ 禁用  │
│ zhangw │ 数据工程师│ zhang@xx │ ✅ 正常 │ 2026-.. │ 详情  │
│        │          │          │        │        │ 编辑  │
│        │          │          │        │        │ 禁用  │
│ ...    │ ...      │ ...      │ ...    │ ...    │ ...   │
├────────┴──────────┴──────────┴────────┴────────┴───────┤
│ 共 25 条  第 1/3 页  [<] [>]                            │
└──────────────────────────────────────────────────────────┘
```

**分页说明**：

- 默认每页 20 条，支持切换为 10/20/50 条每页
- 底部显示"共 X 条，第 Y/Z 页"，左右箭头翻页
- 点击「查询」按当前搜索关键词和筛选条件刷新列表
- 点击「重置」清空搜索框和筛选条件，恢复默认列表
- 搜索和筛选条件变更后不自动刷新，需点击「查询」触发

每一行操作按钮根据用户状态变化：

- 正常用户：显示「详情」「编辑」「禁用」
- 已禁用用户：显示「详情」「编辑」「启用」

#### 5.2.2 创建用户

点击「创建用户」按钮，弹出侧边抽屉或弹窗：

| 字段           | 类型     | 必填 | 说明                                               |
|----------------|----------|------|----------------------------------------------------|
| 用户名         | 文本输入 | ✅   | 登录用，全局唯一，3-30 位字母数字下划线            |
| 初始密码       | 密码输入 | ✅   | 6-20 位，用户首次登录后可自行修改                  |
| 确认密码       | 密码输入 | ✅   | 与初始密码一致                                     |
| 角色           | 下拉多选 | ✅   | 至少选一个。支持一个用户拥有多个角色（权限取并集） |
| 邮箱（可选）   | 文本输入 | —    | 便于联系和找回密码（P2）                           |
| 手机号（可选） | 文本输入 | —    | 便于联系                                           |

底部操作：

- 「创建」按钮 → 成功后抽屉关闭，列表刷新，新用户出现在顶部
- 「取消」按钮 → 抽屉关闭，不保存

**校验规则**：

- 用户名重复 → 输入框下方提示"该用户名已被使用"
- 密码两次不一致 → 确认密码输入框下方提示"两次输入的密码不一致"
- 未选择角色 → 角色下拉框提示"请至少选择一个角色"

#### 5.2.3 编辑用户

点击「编辑」，弹窗内容与创建相同，回填已有信息。编辑时密码字段显示占位符"不修改则留空"——留空表示保持原密码。

#### 5.2.4 禁用/启用用户

点击「禁用」→ 弹出确认："确认禁用用户 `zhangw`？禁用后该用户将无法登录。"，确认后状态变为已禁用，该用户当前会话立即失效。

已禁用用户点击「启用」，仅需确认提示，无额外表单。

#### 5.2.5 用户详情

点击「详情」，进入用户信息页，展示：

- 用户名、角色标签、邮箱、手机号、账号创建时间、最近登录时间
- 下方有「编辑」和「重置密码」两个操作按钮.
- 「重置密码」→ 管理员可为用户设置新密码，新密码生效后用户旧密码立即失效

### 5.3 修改密码（用户自主）

所有用户登录后，点击右上角头像 → 下拉菜单 →「修改密码」，弹出修改密码弹窗：

| 字段       | 说明         |
|------------|--------------|
| 旧密码     | 验证身份     |
| 新密码     | 6-20 位      |
| 确认新密码 | 与新密码一致 |

提交后：

- 成功：绿色提示"密码修改成功"，弹窗关闭
- 旧密码错误：红色提示"旧密码错误"
- 两次新密码不一致：确认框下方红色提示

### 5.4 权限控制——不同角色的体验差异

Sprint 0 完成后，不同角色登录到平台应看到 **不同的菜单结构**：

| 菜单项                 | 超级管理员 | 数据工程师 | 数据分析师                   | 治理管理员 |
|------------------------|------------|------------|------------------------------|------------|
| 数据集成（数据源管理） | ✅         | ✅         | ❌（可查看列表但不可增删改） | ❌         |
| 数据开发（DAG 编排）   | ✅         | ✅         | ❌                           | ❌         |
| 数据治理（元数据管理） | ✅         | ✅（查看） | ✅（查看）                   | ✅（全部） |
| 数据资产目录           | ✅         | ✅         | ✅                           | ✅         |
| 数据服务（SQL 终端）   | ✅         | ✅         | ✅                           | ❌         |
| 系统管理（用户管理）   | ✅         | ❌         | ❌                           | ❌         |

**Sprint 0 阶段的实现方式**：前端根据登录接口返回的 `role` 字段，控制左侧菜单的显隐。后端 API 通过 Sa-Token 注解（
`@SaCheckRole`）拦截无权限的请求，返回"无权限"提示。 **角色和权限矩阵在 Flyway 脚本中预置，无管理界面。**

## 6. 核心用户流程

### 流程 1：管理员创建用户 → 用户登录

```
管理员：
1. 登录（admin / 初始密码）
2. 左侧菜单 → 系统管理 → 用户管理
3. 点击「创建用户」
4. 填写：用户名=zhangw、初始密码=123456、确认密码=123456、角色=数据工程师
5. 点击「创建」→ 成功，列表刷新

新用户：
6. 打开 DataNest → 看到登录页
7. 输入用户名 zhangw、密码 123456
8. 点击「登录」→ 成功 → 跳转首页
9. 左侧菜单只看到：数据集成、数据开发、数据治理（查看）、数据资产目录、数据服务
   （看不到"系统管理"）
```

### 流程 2：用户修改密码

```
1. 用户 zhangw 登录后，点击右上角头像 →「修改密码」
2. 输入旧密码=123456、新密码=Abc@1234、确认新密码=Abc@1234
3. 点击确认 → "密码修改成功"
4. 退出登录 → 重新登录 → 旧密码 123456 提示"密码错误"
5. 输入新密码 Abc@1234 → 登录成功
```

### 流程 3：管理员禁用离职员工

```
1. 管理员进入用户管理列表
2. 找到用户 zhangw，点击「禁用」
3. 弹出确认提示 → 确认
4. zhangw 列表中状态变为 ⛔ 禁用
5. 此时 zhangw 正在使用平台 → 下次操作时提示"账号已被禁用"，跳回登录页
```

## 7. 成功指标

| 指标               | 目标值                                  | 验证方式     |
|--------------------|-----------------------------------------|--------------|
| 登录成功率         | > 99%（排除密码错误）                   | 登录接口统计 |

## 9. 风险

| 风险                         | 缓解                                                              |
|------------------------------|-------------------------------------------------------------------|
| 初始管理员账号泄露           | 首次部署后强制要求修改 admin 密码                                 |
| Token 过期导致用户体验差     | 勾选"记住我"时 Token 7 天有效，否则 2 小时；过期前 5 分钟静默刷新 |
| 权限矩阵随模块增加越变越复杂 | 预置 4 个角色已覆盖核心场景，后续新增角色走自定义角色 + 权限模板  |
