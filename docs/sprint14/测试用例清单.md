## 5. 执行备注与风险

1. **全局配置串行**：所有用例串行（workers=1）；sso-only/规则/策略临时改动必须 finally 恢复。
2. **OIDC 浏览器跳转**：Mock IdP issuer=`http://host.docker.internal:9040`；宿主机已验证可解析（curl 200），E2E 浏览器跳转无需替换 host。若不可达，改为 API 模拟（maxRedirects=0 + 手动替换 localhost）。
3. **dave 用户状态**：SA-09/10/13 会对 dave 清库重建（自动建号/绑定），属测试改动，收尾统一问用户是否清理/恢复。
4. **密码过期断言**：过期登录返回 **code=200 + userInfo.mustChangePwd=true**（非错误码），前端据 mustChangePwd 跳强制改密页。
5. **锁定断言**：第 5 次错误仍返回 PASSWORD_ERROR（设置 locked_until 后抛出），第 6 次（含正确密码）才返回 1008。
6. **产物清理**：跑完清理 `test-results*` / `%TEMP%` 下 s14 临时 ps1/json；测试用户清理先问用户。
