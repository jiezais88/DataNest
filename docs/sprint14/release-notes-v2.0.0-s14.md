# DataNest v2.0.0-s14

Sprint 14 完成企业身份认证与本地账号安全能力，作为二期企业级安全主线的第一阶段交付。

## 企业身份认证

- 支持 OIDC/OAuth2 授权码登录，并在回调后建立 DataNest 本地 Sa-Token 会话。
- 支持 LDAP/AD 域账号登录和目录用户同步。
- 支持按企业身份组/Claim 映射 DataNest 角色。
- 支持已有账号自动绑定、首次登录自动建号，以及解绑后重新绑定。
- 支持混合登录和仅企业身份登录两种模式；`admin` 保留本地登录逃生通道。

## 本地账号安全

- 支持密码最小长度、大写、小写、数字和特殊字符策略。
- 支持密码过期和强制改密。
- 支持连续登录失败锁定和管理员解锁。
- 企业 SSO/LDAP 用户不使用 DataNest 本地密码策略。
- 用户管理展示本地账号、企业 SSO、域账号认证来源，并支持企业身份解绑。

## 审计与体验

- 身份认证配置、LDAP 同步、解绑、解锁、重置密码等管理操作接入审计查询。
- 补齐审计日志中 `SSO_LOGIN`、`LDAP_SYNC`、`UNBIND`、`UNLOCK`、`SSO_CONFIG` 的中文展示和筛选映射。
- 企业 SSO 与 AD 域登录入口统一为同层级有边框按钮；AD 登录使用独立的企业域账号登录框。
- 提供页面版人工验收清单：`docs/sprint14/人工验收清单.md`。

## 环境说明

- Mock OIDC、OpenLDAP 地址和测试账号仅用于开发验收，不属于生产默认配置。
- `docker compose up` 可能触发 Nacos 初始化并重置运行时 SSO 配置；部署后需重新检查身份认证配置。
- 本版本不代表二期正式 `v2.0.0`，后续 Sprint 仍继续在 `feature/phase2` 集成线开发。
