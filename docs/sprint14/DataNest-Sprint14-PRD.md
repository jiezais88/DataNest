# Sprint 14：SSO + 认证安全 PRD

> **文档状态**：v1.0（细化版，承接二期总 PRD §4.1 子模块 A） | **作者**：产品通 | **关联文档**：`../DataNest-二期总PRD.md`（v1.6）、`../DataNest-二期总技术文档.md`（v1.5）、`../sprint0/DataNest-Sprint0-用户与权限管理-PRD.md`（一期认证基准）
>
> **Sprint 目标**：让 DataNest 从「仅本地账号密码登录」升级为「企业统一身份接入」——支持 OIDC/OAuth2 与 LDAP/AD 单点登录，本地账号与 SSO 共存可切换，并强化密码策略（复杂度/过期/失败锁定）。

---

## 1. 问题陈述

### 1.1 为什么 Sprint 14 做这件事

一期 DataNest 只有本地账号密码（BCrypt + Sa-Token）一种登录方式。企业落地时遇到硬瓶颈：

| 场景 | 一期现状 | 后果 |
|------|----------|------|
| 公司已有统一身份体系（钉钉/OA/AD） | 用户每平台一套账号密码 | 密码散落、忘记密码高频、无法统一管理离职 |
| 平台接入企业 IdP（Keycloak/Auth0 等） | 不支持 OIDC | 无法纳入企业单点登录体系 |
| 内部使用 AD 域账号 | 不支持 LDAP | 域用户无法直接用域凭据登录 |
| 弱密码 / 撞库 / 暴力破解 | 仅 6~20 位长度校验 | 密码复杂度无约束、无失败锁定、无过期 |
| 账号来源单一 | 无认证来源字段 | 无法区分本地/SSO/LDAP 用户、无法解绑 |

二期总 PRD 将「企业级安全与可靠性」定位为二期先行主线，SSO 是其第一块能力（Sprint 14）。

### 1.2 Sprint 14 要达到的状态

> 用户可以从企业 IdP 或 AD 域登录 DataNest（自动建号/绑定），本地账号与 SSO 共存且可一键切「仅 SSO」；平台密码策略可配置（复杂度/过期/失败锁定），弱密码与暴力破解被拦截。

## 6. 功能详细交互

### 6.1 F1 OIDC/OAuth2 登录（SSO-01）

**入口**：登录页「企业 SSO 登录」按钮。

```
┌─ 登录 ──────────────────────────────────────────┐
│  [DataNest Logo]                                │
│                                                 │
│  用户名 [________]                               │
│  密码   [________]                               │
│  [记住登录状态]                                  │
│  ┌───────────────────────────────────────────┐  │
│  │          登录                              │  │
│  ├───────────────────────────────────────────┤  │
│  │      [  使用企业 SSO 登录  ]               │  │
│  └───────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

**交互说明**：

- 点击「企业 SSO 登录」→ 跳转 IdP 授权页 → IdP 回调（携带 Authorization Code）→ system-service 换取 token、验签 id_token → 按 `subject` 匹配：
  - **已有绑定**：直接登录；
  - **无绑定但 email/username 命中本地账号**：**自动绑定该本地账号**（认证来源更新为 OIDC），登录；
  - **无命中**：**自动建号**（默认角色，见 6.3）+ 绑定 subject，登录。
- 回调后建立 **本地 Sa-Token 会话**（复用现有 token 体系，登录体验与本地一致）。
- 网关放行 SSO 回调端点（`/auth/sso/oidc/callback` 等）。
- **配置缺失/IdP 不可达**：提示「SSO 未配置或不可达，请用本地账号登录」。

### 6.2 F2 LDAP/AD 接入（SSO-02）

**入口**：登录页「AD 域登录」按钮（或独立域名输入）。

```
┌─ 登录 ──────────────────────────────────────────┐
│  ...（本地表单 / SSO 按钮同上）                   │
│  [  使用 AD 域账号登录  ]                        │
└─────────────────────────────────────────────────┘
```

**交互说明**：

- 域登录：输入 `域账号 + 域密码` → system-service 绑定 LDAP 校验（bind DN）→ 按 `sAMAccountName/uid` 匹配/自动建号（同 6.1 规则）→ 建本地 Sa-Token 会话。
- **用户同步**：身份认证页提供「同步用户」按钮（及可选定时任务）——从配置的 OU 拉取用户，自动建号并关联角色映射；同步日志展示新增/更新/跳过。
- 同步的 LDAP 用户密码由域管理，平台不存其密码（认证来源 = LDAP）。

### 6.3 F3 角色映射（SSO-03）

**入口**：系统管理 → 身份认证 → 角色映射。

```
┌─ 角色映射规则 ─────────────────────────────────┐
│  IdP group/claim 值        →  平台角色         │
│  ┌──────────────────────┬──────────────────┐  │
│  │ datanest-engineers   │  数据工程师      │  │
│  │ datanest-analysts    │  数据分析师      │  │
│  │ datanest-admins      │  治理管理员      │  │
│  │ （未匹配）           │  数据分析师(默认)│  │
│  └──────────────────────┴──────────────────┘  │
│  [新增规则] [默认角色：数据分析师 ▾]             │
└────────────────────────────────────────────────┘
```

**交互说明**：

- 映射规则存 Nacos（`datanest.sso.role-mapping`），**可配置**。
- 登录时按 IdP `group/roles` claim 匹配规则 → 赋予对应平台角色；**未匹配给默认角色**（默认角色可配置，默认数据分析师）。
- **映射为主 + 平台手动为辅**：管理员可在用户管理手动调整角色，下次登录时若 claim 仍命中规则则重新映射（手动调整在未重新命中前保留）。

### 6.4 F4 登录模式（SSO-04）

**入口**：系统管理 → 身份认证 → 登录模式。

```
┌─ 登录模式 ─────────────────────────────────────┐
│  (●) 混合登录：本地账号 + SSO 均可登录         │
│  ( ) 仅 SSO：只允许企业身份登录                 │
│      注：admin 始终保留本地密码登录（逃生通道） │
└────────────────────────────────────────────────┘
```

**交互说明**：

- **混合（默认）**：登录页显示本地表单 + SSO/LDAP 按钮。
- **仅 SSO**：登录页隐藏本地表单（仅显示企业 SSO/AD 按钮）；**admin 例外**——admin 仍可用本地密码登录（紧急逃生通道，避免 SSO 配置错误锁死平台）。

### 6.5 F5 密码策略（SSO-05）

**入口**：系统管理 → 身份认证 → 密码策略。

```
┌─ 密码策略（仅本地账号生效） ──────────────────┐
│  复杂度                                       │
│  ☑ 最小长度 8 位                               │
│  ☑ 需包含大写字母 / 小写字母 / 数字 / 特殊字符   │
│                                               │
│  过期                                         │
│  ☑ 密码有效期 90 天                            │
│  □ 到期前 7 天提醒                             │
│                                               │
│  登录失败锁定                                  │
│  ☑ 连续失败 5 次锁定 30 分钟                   │
│  [保存]                                       │
└────────────────────────────────────────────────┘
```

**交互说明**：

- **复杂度**：最小长度、必须包含的字符类别可配置；创建/修改/重置密码时校验。
- **过期**：密码到期后本地登录要求强制改密（改密前不可进入系统）。
- **失败锁定**：连续失败达阈值锁定账号（或临时锁定），锁定期间本地登录被拒；管理员可重置。
- **生效范围：仅本地密码用户**（认证来源 = LOCAL）；SSO/LDAP 用户不受影响。
- `sys_user` 新增字段：`auth_source`、`password_expire_at`、`login_fail_count`、`locked_until`。

### 6.6 F6 账号绑定管理（P1）

**入口**：用户管理 → 用户详情。

```
┌─ 用户详情 · 王峰 ─────────────────────────────┐
│  基本信息：用户名 / 邮箱 / 状态 / ...           │
│  认证来源：OIDC（已绑定 IdP subject: abc-123）  │
│  [解绑]（解绑后该用户只能用本地密码登录）       │
└────────────────────────────────────────────────┘
```

**交互说明**：

- 用户列表/详情展示**认证来源**徽章（本地/OIDC/LDAP）。
- 已绑定 IdP 的用户可**解绑** subject（解绑后 SSO 登录不再命中该账号，需本地密码登录）。

> 技术实现（表结构、索引、Flyway 迁移）归 `DataNest-Sprint14-技术文档.md`。

## 8. 存量迁移与升级

| 迁移项 | 方案 |
|--------|------|

| 升级体验 | 一期本地登录完全不变；SSO 配置前登录页无 SSO 按钮（或隐藏） |

## 10. 验收标准

### 10.1 功能验收

| # | 验收项 | 验收标准 |
|---|--------|----------|
| AC-1 | OIDC 登录 | 配置 OIDC 后可从 IdP 登录；首次自动建号/绑定；同 subject 再次登录直接进 |
| AC-2 | LDAP 登录 | 域账号可直接登录；配置 OU 可同步用户并关联角色 |
| AC-3 | 角色映射 | claim 命中规则 → 对应角色；未命中 → 默认角色；映射规则可配置 |
| AC-4 | 登录模式 | 混合两路可登；切「仅 SSO」后本地表单隐藏、admin 仍可本地登录 |
| AC-5 | 密码复杂度 | 设置复杂规则后，弱密码（不含大写/过短等）创建/改密被拒 |
| AC-6 | 密码过期 | 到期后本地登录要求强制改密；SSO 用户不受影响 |
| AC-7 | 失败锁定 | 连续失败达阈值锁定，锁定期间本地登录被拒；可重置 |
| AC-8 | 账号绑定 | 用户详情显示认证来源；解绑后 SSO 登录不再命中该账号 |
| AC-9 | 存量兼容 | 一期本地用户登录行为不变；SSO 可绑定已有本地账号 |

### 10.2 非功能验收

| # | 项 | 标准 |
|---|-----|------|
| N-1 | 安全 | 密码 BCrypt 存储；OIDC state 防 CSRF；回调 token 校验严格 |
| N-2 | 可用性 | SSO 配置缺失/IdP 不可达时优雅降级提示，不阻断本地登录 |
| N-3 | 审计 | SSO 登录、LDAP 同步、解绑、密码策略修改均留审计 |

## 11. 风险与对策

| # | 风险 | 影响 | 对策 |
|---|------|------|------|
| R1 | **SSO 配置错误导致全员无法登录** | 平台不可用 | 「仅 SSO」时 admin 保留本地登录逃生通道；配置项先行校验 |
| R2 | **自动建号误绑他人账号**（email 冲突） | 越权 | 同名自动绑定需同时校验 subject 唯一性；解绑可回退 |
| R3 | **LDAP 同步数据量大/账号误删** | 账号错乱 | 同步仅新增/更新，不删除平台账号（下线用禁用）；同步日志留痕 |
| R4 | **claim 角色覆盖管理员手动调整** | 权限错乱 | 手动调整优先保留（未重新命中规则前不覆盖） |
| R5 | **锁定策略误伤正常用户** | 无法登录 | 锁定可重置、阈值可配置；锁定前登录页明确提示 |
