## 一、血缘可视化

### 1.1 表级血缘图谱入口

- **验收项**：元数据详情页可进入血缘图谱
- **操作步骤**：
    1. 登录超管账号，进入「数据治理 → 元数据管理」
    2. 点击任意已存在血缘的表名，进入详情页
    3. 点击「血缘图谱」按钮
- **验收标准**：
    - [ ] 详情页出现「血缘图谱」按钮
    - [ ] 点击后跳转至 `/governance/metadata/lineage`
    - [ ] 页面标题为「血缘图谱」

### 1.2 表级血缘图谱渲染

- **验收项**：图谱正确展示当前表及上下游节点
- **操作步骤**：
    1. 进入血缘图谱页面（带存在血缘的表名参数）
    2. 观察画布节点、边、当前表高亮
- **验收标准**：
    - [ ] 当前表节点显示「当前表」标签
    - [ ] 上游表、下游表均渲染为节点
    - [ ] 节点之间有指向当前表/从当前表指出的边
    - [ ] 节点名、库名展示正确

### 1.3 展开层级

- **验收项**：支持调整血缘展开深度
- **操作步骤**：
    1. 在血缘图谱页找到「展开层级」控件
    2. 切换 depth=1 / depth=2 / depth=3
- **验收标准**：
    - [ ] depth=1 展示直接上下游
    - [ ] depth=2 在不产生新链路时不新增冗余节点
    - [ ] 过大 depth（如 10）不报错，按上限处理

### 1.4 影响分析

- **验收项**：点击「影响分析」后高亮下游链路
- **操作步骤**：
    1. 进入血缘图谱页
    2. 点击「影响分析」按钮
    3. 点击当前表或下游表节点
- **验收标准**：
    - [ ] 提示文案切换为分析模式
    - [ ] 被点击节点到其下游的链路高亮
    - [ ] 未选中链路保持原样或置灰

### 1.5 溯源分析

- **验收项**：点击「溯源分析」后高亮上游链路
- **操作步骤**：
    1. 进入血缘图谱页
    2. 点击「溯源分析」按钮
    3. 点击当前表或上游表节点
- **验收标准**：
    - [ ] 提示文案切换为溯源模式
    - [ ] 被点击节点到其上游的链路高亮

### 1.6 字段级血缘下钻

- **验收项**：打开字段级血缘面板，展示列→列映射
- **操作步骤**：
    1. 进入血缘图谱页
    2. 点击「字段血缘」按钮
    3. 在字段下拉框中选择不同字段
- **验收标准**：
    - [ ] 字段级血缘面板正常弹出
    - [ ] 默认选中字段并展示「当前字段」
    - [ ] 展示来源字段节点、目标字段节点
    - [ ] 字段之间存在血缘边

### 1.7 无血缘空状态

- **验收项**：无血缘的表展示空状态提示
- **操作步骤**：
    1. 进入一个不存在血缘关系的表的血缘图谱页
- **验收标准**：
    - [ ] 页面显示「暂无血缘数据」
    - [ ] 显示引导文案（如「可通过以下方式产生血缘」）
    - [ ] 不展示无意义的孤立节点或虚假边

### 1.8 血缘可视化权限

- **验收项**：分析师也能查看血缘图谱
- **操作步骤**：
    1. 分别使用超管、工程师、治理员、分析师账号登录
    2. 均访问血缘图谱页面
- **验收标准**：
    - [ ] 四个角色均可正常查看图谱
    - [ ] 未登录用户访问返回未登录提示或跳转登录页

## 二、全局告警中心

### 2.1 告警中心菜单可见性

- **验收项**：系统管理下新增「告警中心」菜单
- **操作步骤**：
    1. 使用超管/工程师/治理员账号登录，查看左侧菜单
    2. 使用分析师账号登录，查看左侧菜单
- **验收标准**：
    - [ ] 超管、工程师、治理员可见「告警中心」菜单
    - [ ] 分析师不可见「告警中心」菜单

### 2.2 告警规则列表

- **验收项**：告警中心规则 Tab 展示规则列表
- **操作步骤**：
    1. 进入「系统管理 → 告警中心」
    2. 确保已存在告警规则（可提前通过页面新增）
- **验收标准**：
    - [ ] 列表展示对象名称、对象类型、触发条件、状态、接收人
    - [ ] 支持按对象类型筛选
    - [ ] 支持按对象名/关键字搜索
    - [ ] 分页正常

### 2.3 新增告警规则

- **验收项**：可新增 DAG / 同步任务 / 采集任务三类告警规则
- **操作步骤**：
    1. 点击「新增告警规则」
    2. 选择对象类型、选择对象、勾选触发条件（失败/成功/超时）
    3. 选择接收用户，设置超时阈值
    4. 保存
- **验收标准**：
    - [ ] 三类对象均可选择
    - [ ] 仅显示有邮箱的用户
    - [ ] 保存后规则出现在列表中
    - [ ] 对象重复时给出明确提示

### 2.4 编辑/启用/停用/删除规则

- **验收项**：规则可操作全生命周期
- **操作步骤**：
    1. 在规则列表点击「编辑」，修改触发条件和接收人，保存
    2. 点击「停用」，观察状态变化
    3. 点击「启用」，观察状态变化
    4. 点击「删除」，确认弹窗后删除
- **验收标准**：
    - [ ] 编辑后列表实时刷新
    - [ ] 停用后状态显示「停用」
    - [ ] 启用后状态显示「启用」
    - [ ] 删除后列表中不再出现

### 2.5 告警历史

- **验收项**：告警历史 Tab 展示发送记录
- **操作步骤**：
    1. 切换到「告警历史」Tab
    2. 观察列表字段和筛选
- **验收标准**：
    - [ ] 列表展示对象名、告警类型、接收人、发送状态、发送时间
    - [ ] 支持按对象类型、告警类型、发送状态筛选
    - [ ] 点击详情可查看邮件内容/失败原因

### 2.6 同步任务告警快捷入口

- **验收项**：同步任务列表可操作告警配置
- **操作步骤**：
    1. 进入「数据工程 → 批量数据同步任务」
    2. 点击某任务操作列的「告警配置」图标
- **验收标准**：
    - [ ] 弹出告警规则配置弹窗
    - [ ] 弹窗内对象类型已固定为「同步任务」
    - [ ] 保存后与告警中心规则列表同源

### 2.7 采集任务告警快捷入口

- **验收项**：采集任务列表可操作告警配置
- **操作步骤**：
    1. 进入「数据治理 → 采集任务」
    2. 点击某任务操作列的「告警配置」图标
- **验收标准**：
    - [ ] 弹出告警规则配置弹窗
    - [ ] 弹窗内对象类型已固定为「采集任务」

### 2.8 DAG 告警快捷入口

- **验收项**：DAG 编辑器内可操作告警配置
- **操作步骤**：
    1. 进入「数据工程 → 项目管理」并打开某个 DAG
    2. 点击编辑器内「告警配置」按钮
- **验收标准**：
    - [ ] 弹出告警规则配置弹窗
    - [ ] 弹窗内对象类型已固定为「DAG」
    - [ ] 保存后在告警中心列表可见

### 2.9 告警触发与邮件

- **验收项**：任务失败/成功时触发邮件告警
- **操作步骤**：
    1. 为同步任务或 DAG 配置「失败」告警规则
    2. 手动执行该任务，使其失败
    3. 查看 MailHog 或邮件收件箱
- **验收标准**：
    - [ ] 告警历史出现 FAILURE 记录
    - [ ] 发送状态为「发送成功」
    - [ ] 邮件主题/正文包含任务名与「执行失败」

### 2.10 告警中心权限

- **验收项**：治理员可查看但不可编辑
- **操作步骤**：
    1. 使用治理员账号进入告警中心
    2. 尝试新增、编辑、删除规则
- **验收标准**：
    - [ ] 治理员可见列表和历史
    - [ ] 治理员无「新增告警规则」按钮
    - [ ] 治理员的编辑/删除按钮禁用或点击后提示无权限

## 三、DAG 控制流增强

### 3.1 节点面板展示

- **验收项**：DAG 编辑器节点面板新增条件分支、子 DAG
- **操作步骤**：
    1. 进入 DAG 编辑器（新建或编辑 DAG）
    2. 查看左侧节点面板
- **验收标准**：
    - [ ] 节点面板出现「条件分支」节点
    - [ ] 节点面板出现「子 DAG」节点

### 3.2 条件分支节点拖拽与配置

- **验收项**：可拖拽条件分支节点并配置分支
- **操作步骤**：
    1. 从节点面板拖入「条件分支」节点到画布
    2. 双击节点打开配置弹窗
    3. 配置多个分支表达式，选择下游节点
    4. 保存 DAG
- **验收标准**：
    - [ ] 画布出现条件分支节点
    - [ ] 弹窗展示默认分支（expression=true）
    - [ ] 可添加/删除分支
    - [ ] 每个分支可配置表达式和 nextNodeId
    - [ ] 保存后刷新，分支配置不丢失

### 3.3 条件分支保存校验

- **验收项**：配置不完整时保存被拦截
- **操作步骤**：
    1. 拖入条件分支节点
    2. 不配置完整分支表达式或 nextNodeId
    3. 点击保存 DAG
- **验收标准**：
    - [ ] 前端提示「存在未完整配置的分支」
    - [ ] 少于 2 个分支、空表达式、指向不存在节点均应拦截

### 3.4 条件分支真实执行

- **验收项**：DAG 执行时按条件选择分支
- **操作步骤**：
    1. 创建 DAG：SQL 节点 → 条件分支节点 → 分支 A / 分支 B
    2. SQL 节点返回 2 行数据
    3. 配置分支表达式：`${upstream.row_count} > 0`
    4. 执行 DAG，观察节点状态
- **验收标准**：
    - [ ] 当上游行数 >0 时，命中非默认分支，默认分支被跳过
    - [ ] 当上游行数 =0 时，走默认分支
    - [ ] 被跳过分支状态为 SKIPPED

### 3.5 子 DAG 节点拖拽与配置

- **验收项**：可拖拽子 DAG 节点并选择子 DAG
- **操作步骤**：
    1. 从节点面板拖入「子 DAG」节点到画布
    2. 双击节点打开配置弹窗
    3. 选择一个已存在的子 DAG
    4. 设置同步/异步执行
    5. 保存 DAG
- **验收标准**：
    - [ ] 画布出现子 DAG 节点
    - [ ] 弹窗可搜索并选择子 DAG
    - [ ] 可切换同步执行 / 异步执行
    - [ ] 保存后刷新，子 DAG 配置不丢失

### 3.6 子 DAG 保存校验

- **验收项**：未选择子 DAG 或选择非法子 DAG 时保存被拦截
- **操作步骤**：
    1. 拖入子 DAG 节点但不选择子 DAG，保存
    2. 选择不存在的 DAG，保存
    3. 选择已禁用的 DAG，保存
- **验收标准**：
    - [ ] 未选择子 DAG：前端提示「未选择子 DAG」
    - [ ] 子 DAG 不存在：后端返回错误提示
    - [ ] 子 DAG 未启用：后端返回错误提示

### 3.7 子 DAG 循环引用检测

- **验收项**：保存时检测并阻断循环引用
- **操作步骤**：
    1. 创建 DAG A、DAG B
    2. 在 B 中引用 A 为子 DAG 并保存
    3. 在 A 中引用 B 为子 DAG 并保存
- **验收标准**：
    - [ ] A 保存失败，提示存在循环引用
    - [ ] 直接在 DAG 中引用自身也提示循环引用

### 3.8 子 DAG 删除守卫与级联告警

- **验收项**：被引用的 DAG 不能删除，删除 DAG 时级联删除告警规则
- **操作步骤**：
    1. 创建子 DAG，再在父 DAG 中引用它
    2. 尝试删除子 DAG
    3. 为某 DAG 配置告警规则后删除该 DAG
- **验收标准**：
    - [ ] 被引用的 DAG 删除失败，提示被引用
    - [ ] 先删除父 DAG 后可正常删除子 DAG
    - [ ] DAG 删除后，其告警规则同步被清理

## 执行建议

1. **环境准备**：
    - 前端：`http://localhost:3000`
    - 后端：`http://localhost:8080/api`
    - 预置账号：admin / s5_engineer / s5_govadmin / s5_analyst
2. **执行顺序**：
    - 先做「血缘可视化」模块，确认图谱渲染正常
    - 再做「全局告警中心」，验证规则 CRUD 和邮件触发
    - 最后做「DAG 控制流增强」，重点验证条件分支和子 DAG 的真实执行
3. **重点回归**：
    - 血缘图谱边渲染（P0，历史缺陷）
    - 条件分支默认分支恒命中问题（P1，历史缺陷）
    - 子 DAG 节点状态 SKIPPED 问题（P1，历史缺陷）
    - 告警中心规则编辑时对象被清空问题（历史缺陷）
